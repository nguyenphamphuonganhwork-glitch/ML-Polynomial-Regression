# ML Polynomial Regression

This is a machine learning project based on concepts
from Pattern Recognition and Machine Learning (PRML)
by Christopher Bishop.

## Project Description

This project explores polynomial regression and model
selection using a dataset of 199 samples.

## Dataset

Input:
- Study hours per day

Target:
- Exam score

## Methods

- Polynomial regression
- Least Squares
- Gaussian likelihood
- Maximum Likelihood Estimation
- Cross-validation

## Libraries

- NumPy
- Matplotlib
